# Userscripts

A collection of Tampermonkey/Greasemonkey userscripts.

---

## Scripts

### [Humble Bundle Key Extractor](humblebundle-key-extractor.user.js)
Extracts and copies game keys from Humble Bundle purchase, download, and membership pages. Auto-reveals unrevealed keys and can auto-redeem them directly on Steam.

**Matches:** `humblebundle.com/home/purchases`, `/downloads`, `/*/p/*`, `/membership`

---

### [Fanatical Enhanced](fanatical-enhanced.user.js)
Adds copy-to-clipboard buttons to game keys on Fanatical order pages.

**Matches:** `fanatical.com/*/orders/*`

---

### [Fanatic Anime Store — Remove Out of Stock](fnc-cleaner.user.js)
Hides out-of-stock product cards and their parent containers, eliminating blank spaces on browse/search pages.

**Matches:** `fanaticanimestore.com/*`

---

### [Gamedle Image Viewer](gamedle-viewer.user.js)
Adds a cheat button that reveals the full answer images on Gamedle.wtf pages. Useful for long weekly games.

**Matches:** `gamedle.wtf/*`

---

### [ES Monster Patreon → Cults3D Promo Code Extractor](patreon-cults.user.js)
Scrapes promo codes from ES Monster Patreon posts and sequentially auto-applies them to your Cults3D cart.

**Matches:** `patreon.com/posts/*`, `cults3d.com/en/cart`
